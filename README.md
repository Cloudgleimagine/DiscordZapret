> ### АНТИВИРУСЫ
> WinDivert способен вызвать срабатывание антивируса.  
> Это средство перехвата и фильтрации трафика, необходимое для работы zapret.
> WinDivert может применяться как безопасными, так и вредоносными программами, однако сам по себе вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают файлы WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. В таком случае детект обычно называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку с zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы точно понимаете настройки исключений, предпочтительно добавить исключение. Если нет — рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS, отличный от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` (провайдер Cloudflare может быть заблокирован)
    * Windows 11 позволяет активировать Secure DNS непосредственно в настройках ОС — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Его отключение способно помешать настройке и работе Secure DNS на компьютере

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/Cloudgleimagine/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте "Разблокировать". При использовании 7-Zip или PeaZip этот этап можно пропустить

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для автоматического запуска перейдите в **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **проверяйте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние (включено/выключено).
  - **`IPSet Filter`** — переключить режим обхода сервисов из `ipset-all.txt`.  
  Опция пригодится при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках показывается текущий режим:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP проверяются на наличие в списке
    - `any` — под фильтр попадает любой IP
  - **`Auto-Update Check`** — включить или выключить автоматическую проверку обновлений
  - **`Replace active fakes`** — заменить используемый fake на другой из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — выполнить проверку обновлений
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это может помочь при внезапной остановке его работы
  - **`Run Tests`** — открыть инструмент проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и проблемы

### После запуска `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues/522)

### Не работает ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram (веб-версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - В появившейся папке откройте файл `hosts` через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированный текст в конец `hosts` либо замените им ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение ещё раз. Если проблема останется, убедитесь, что `hosts` действительно сохранился.

#### Работа не гарантируется. Если этот способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Cloudgleimagine/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Стратегия способна работать некоторое время, а затем перестать работать после её обнаружения.
> В репозитории есть множество вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из представленных, изменив её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте отсутствие ошибок

- Убедитесь, что адрес нужного ресурса присутствует в списках доменов или IP

- Проверьте другие варианты (**`ALT`**, **`FAKE`** и прочие)

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Откройте `service.bat` -> `Remove Services`
- Затем выполните `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их и в конце ответьте Y
- Удалите каталог zapret
- Загрузите последнюю версию [со страницы релизов](https://github.com/Cloudgleimagine/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите «Применить» и «ОК»
- Распакуйте архив в новую папку в корне диска, не используя специальные символы и пробелы
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если доступ не появился, закройте программу через значок замка на панели задач и попробуйте другую стратегию
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтр может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Изучите инструкцию: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Получите имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Отключите блокировщик рекламы: известно, что YouTube начал бороться с такими расширениями.
- Переберите остальные стратегии, особенно если прежняя раньше работала
- Дополнительно смотрите [#251](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить именно её
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею
- Если Discord не работает и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Cloudgleimagine/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Самый универсальный порядок действий:
- через `service.bat` обновите ipset и включите `Game Filter`
- если результата нет, дополнительно включите `ipset any`

Учтите, что режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно: определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если это также не помогло, создайте обсуждение в разделе [Discussions](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Моей проблемы нет в списке

- Опишите её [здесь](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен этой сети фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** автоматически создаются при первом запуске `zapret` или `service.bat`
